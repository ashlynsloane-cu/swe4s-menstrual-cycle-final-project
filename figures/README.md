The exports are grouped by scientific aim, not by the date they were
created or committed. The original primary analyses are preserved.

Aim 1 includes additional distance-metric sensitivity figures developed
in response to the Moore–Fairborn code review. These evaluate regularized
Mahalanobis distance alongside the original standardized Euclidean
distance analysis.

For the methods and reproduction instructions, see
[Aim 1](aim1/README.md), [Aim 2](aim2/README.md), and the
[main README](../README.md).
